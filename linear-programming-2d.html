💡 教學要點

  • Linear inequality 嘅意思：ax+by+c \le 0 唔係一條線，而係一個半平面。先畫條界線 ax+by+c=0，再用 test point（通常 (0,0)）決定邊一邊係解。
  • Feasible region：所有 constraints 同時滿足嘅重疊區域（圖中藍色陰影）。每一點 (x,y) 都係一組可行嘅方案。
  • Linear programming 嘅意思：喺 feasible region 入面，搵令 P=mx+ny+r 最大同最小嘅兩點。P 可以係利潤（求 max）或成本（求 min）。
  • Corner point theorem：最大同最小值一定喺可行域嘅頂點（corner point）出現。所以唔使試無限咁多點，逐隻角計 P 就得。
  • 動畫解說：將 P=mx+ny+r 寫成 y=-\dfrac{m}{n}x+\dfrac{P-r}{n}，斜率固定，P 改變即係條線上下平移。由細掃到大：第一隻掂到嘅角係 minimum，最後離開嘅角係 maximum。
  • Strict inequality（> / <）點處理：界線畫虛線，唔包在內。角點如果喺條 strict 界線上，會畫空心圓 ○——意思係 P 可以無限趨近嗰個值，但取唔到，所以只有 supremum／infimum，無真正 max／min。
  • 無界 (unbounded) 情況：如果可行域伸延到無限遠，P 可能無 maximum（\to +\infty）或無 minimum（\to -\infty），圖會標示 ⚠️。
