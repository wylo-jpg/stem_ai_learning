🔀 條件句大師

玩法：每題係一句條件句（if-句），揀返正確嘅動詞形式填入空格。每題限時 20 秒，共 10 題，連擊有加成！

💡 文法概念 — 四種條件句：
類型if-子句主句
Type 0
真理／習慣		Present SimplePresent Simple
Type 1
將來可能		Present Simplewill + 原形
Type 2
與現在相反		Past Simplewould + 原形
Type 3
與過去相反		Past Perfectwould have + 過去分詞
例：If you heat ice, it melts.（Type 0）／ If I were rich, I would travel.（Type 2）
