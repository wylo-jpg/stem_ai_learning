🪜 比較級階梯

玩法：上面會出一個形容詞原形（例如 tall）。撳下面嘅選項，將比較級（taller）同最高級（tallest）分別放入兩格，撳錯格可以撳返嚟清除，最後撳「確定答案」。兩格都啱先有分（+150）！共 8 題。

💡 文法概念 — 比較級規則：
• 短字（1-2 音節）：加 -er / -est（tall → taller → tallest）
• 長字（3+ 音節）：用 more / most（beautiful → more beautiful → most beautiful）
• 不規則：good → better → best；bad → worse → worst
• 比較級 + than；最高級 + the！
