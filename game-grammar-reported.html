⌨️ 打字轉述

玩法：上面有一句直接引語（Direct Speech），你要用鍵盤親手打出間接引語（Reported Speech）！唔使理大細楷同標點，意思啱就得。共 8 題，答啱 +100 分。

💡 文法概念（時態退後一級）：
• am/is → was；are → were
• can → could；will → would
• have done → had done；did → had done
• 問句轉陳述句語序：Do you…? → if I…；Where…? → where I…
